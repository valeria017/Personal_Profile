# Personal Profile

Personal portfolio website for Valeria Li.

## Files

- `index.html` — website structure and content
- `style.css` — visual design and responsive layout

## GitHub Pages

This repository can be published through GitHub Pages.

In the repository, go to:

**Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save**

The site will then be available at:

`https://valeria017.github.io/Personal_Profile/`

Before publishing, replace `YOUR_EMAIL` and `YOUR_LINKEDIN_URL` in `index.html`.
